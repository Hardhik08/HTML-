System Guide
How this recommendation system works
This demo tracks anonymous shoppers, estimates what product category each shopper is most interested in, and then chooses an offer for that shopper when the confidence is high enough.

Who receives the offer?

The system suggests an offer to the shopper whose on-screen profile shows enough intent. In the simulation, every shopper has an anonymous ID like C-214, and offers are tied to that ID.

How is the offer chosen?

First, the engine finds the shopper's highest-interest category from dwell time and revisits. Then it mixes that best category with a Thompson-sampling bandit so it can still test alternatives.

Decision flow

  • Detect the shopper and assign an anonymous ID.
  • Track which zone the shopper stays in and how often they return.
  • Convert that behavior into category interest scores.
  • Trigger an offer only when the strongest score crosses the minimum threshold.
  • Learn from accept or ignore feedback to improve future choices.
On the dashboard itself, only the selected shopper, current recommendation, and key metrics are shown so the view stays stable and easy to read.
